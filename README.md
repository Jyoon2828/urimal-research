# 우리말 탐구 자료실

초등학교 4학년 학생이 우리말 사용 전반을 조사할 때 사용하는 **읽기 전용 자료실**입니다. 글은 교과서에 씁니다. 글쓰기, 제출, 로그인, 학생 정보 수집 기능은 없습니다.

## 포함된 기능

- 줄임말·신조어 / 외래어·외국어 / 욕설·거친 말 / 온라인 언어 / 세대별 언어 / 바르고 쉬운 우리말: 6개 메뉴
- 확인한 원문 14곳을 바탕으로 구성한 자료 카드 18개 (동일 자료가 관련 메뉴에 함께 표시됨)
- 조사 결과·그래프, 전문가 인터뷰, 현장 의견, 공식 안내 자료 필터
- 자료 검색, 최신 공개 자료 순 정렬, 글씨 크기 조절
- 확대 읽기 화면: 쉬운 요약, 조사 대상·기간, 그래프와 표, 해석할 때의 주의점, 원문 링크, 출처
- 그래프는 실제 조사 수치로 다시 그렸습니다. 인터넷 연결 없이 카드와 그래프를 읽을 수 있습니다. 원문 링크는 인터넷 연결이 필요합니다.

## 바로 확인하기

압축을 풀고 `index.html`을 크롬이나 엣지로 열면 됩니다. 별도 설치가 필요하지 않습니다. 모든 파일은 같은 폴더 구조로 유지하세요.

## GitHub → Vercel 배포

1. GitHub에서 새 저장소를 만듭니다. 예: `urimal-research`.
2. 압축을 푼 폴더 **안의 파일들**을 저장소에 업로드하고 커밋합니다. 저장소 최상위에 `index.html`, `app.js`, `data.js`, `style.css`, `vercel.json`이 있어야 합니다.
3. Vercel에서 **Add New → Project**를 선택하고 해당 저장소를 가져옵니다.
4. Framework Preset은 **Other**, Root Directory는 저장소 최상위로 둡니다.
5. 별도 Build Command나 환경 변수는 필요하지 않습니다. `vercel.json`에 정적 배포 설정이 있습니다. Output Directory는 `.`입니다.
6. **Deploy**를 누릅니다. 생성된 공개 주소를 학생들에게 안내합니다.

Firebase, API 키, 데이터베이스, 유료 서비스 연결 없이 동작합니다. 이 파일을 전달하는 시점에 GitHub 저장소 업로드 및 Vercel 실제 배포는 수행되지 않았습니다.

## GitHub Pages도 사용 가능

저장소 Settings → Pages → Deploy from a branch → main / (root) → Save. 주소의 저장소 경로 아래에서도 상대 경로로 동작합니다.

## 자료 수정

`data.js`에 메뉴와 자료가 있습니다. 자료 추가 시 반드시 원문에서 수치·조사 대상·조사 기간·문항의 기준을 확인하세요. `checked`와 화면 하단의 확인일도 함께 갱신하세요. 자동 뉴스 수집이나 자동 자료 갱신은 없습니다.

조사 자료에 `type: 'stats'`, 인터뷰에 `type: 'interview'`, 현장 의견에 `type: 'opinion'`, 공식 안내에 `type: 'guide'`를 사용합니다. 학생이 직접 조사하거나 면담한 것처럼 표시하지 않습니다. 대상을 초등학생으로 바꾸어 적거나, 복수응답을 전체 학생 피해율로 해석하지 마세요.

## 확인한 범위

- 공식 보고서 원문에서 국민 언어 의식 조사 수치와 조사 개요, 사이버폭력 수치를 대조했습니다.
- 교육부 2026년 9월 공식 카드뉴스의 그래프와 현장 의견을 확인했습니다.
- 전문가 의견은 실제 기사 본문과 인물의 소속을 확인했습니다.
- JavaScript 문법, 데이터 무결성, 메뉴·검색·필터·확대 읽기·표·출처 화면의 렌더링을 자동 확인했습니다.
- 이 작업 환경의 브라우저 검증 기능이 제공되지 않아 실제 태블릿·브라우저 화면을 직접 검증하지는 못했습니다. 배포 후 학생용 갤럭시탭에서 한 번 확인하세요.

자료의 상세 확인 기록은 `SOURCES.md`에 있습니다.

## 전문가 의견 읽기 자료 수정

전문가 인터뷰 2개와 현장 의견 1개에 3~4문단의 학생용 읽기 자료를 넣었습니다. 방송 표현의 쓰임·듣는 사람의 경험·전문가 의견을 구분합니다. 문단 번호, 접어서 보는 낱말 풀이, 답이 제공되지 않는 자료 탐색 질문 3개를 제공합니다. 결론을 제시하는 카드 소개문도 중립적인 안내로 수정했습니다.

## 전문가·뉴스 자료 추가

성영태 교수의 공공기관 이름 의견, 김한빛나리 국장·김슬옹 원장의 도시 표어 의견, 유현재 교수의 온라인 댓글 발언을 추가했습니다. 한글문화연대 기자단의 세대 소통 글과 사이버폭력 조사 뉴스도 추가했습니다. 전문가 발언을 전한 기사와 기자단의 해석을 구분하며, 각 자료는 학생용 3문단과 낱말 풀이·탐색 질문을 제공합니다.
